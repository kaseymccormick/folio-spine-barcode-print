1. Library of Congress (LC)
LC labels are read as a stack of lines, top to bottom:

Class letter(s) + number (e.g., QA76.73) — subject area
Cutter number for author/main entry (e.g., .C15) — starts with a period, alphanumeric
Sometimes a second cutter for title or subject subdivision
Year of publication at the bottom, if there's room

The whole thing sorts like a call number you'd find in a catalog — it's shelved by subject first, then alphabetically by author within that subject.

2. Dewey Decimal
Simpler, three-line structure:

Class number (e.g., 813.54) — the subject classification
Book/Cutter number, usually the first 1-3 letters of the author's last name or a Cutter table number (e.g., B738 for Brontë)
Optional: date, volume, or copy number

Public libraries often just use the first letters of the author's name instead of formal Cutter numbers, which is why you'll see labels like "FIC SMI" on fiction shelves.

3. SuDoc (Superintendent of Documents)
This one's structurally different because it's organized by issuing government agency, not subject:

Agency letter/number (e.g., Y4 = Congress, C 3 = Census Bureau)
Sub-agency or series number after a period
Book/item number after a colon
Example: Y 4.AG 8/1: EN 2/2

Because it groups by agency, related documents from the same office end up shelved together regardless of topic — useful for gov docs collections, but it doesn't map to subject-based browsing the way LC or Dewey do.
